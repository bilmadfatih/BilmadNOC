# Release Notes - Bilmad NOC v0.2.0

## Yeni Özellikler

- Core UI iskeleti yenilendi.
- Sol menü, topbar ve dark tema geliştirildi.
- Ana dashboard eklendi.
- TV'de açık kalacak NOC Wall ekranı eklendi.
- Partner kullanımı için CCTV / Alarm Wall ekranı eklendi.
- Integration modeli eklendi.
- Demo veri oluşturmak için `seed_demo` komutu eklendi.

## Hazırlanan Modül Temelleri

- Berqnet SASE
- VMware ESXi / vCenter
- Narbulut Backup
- Sensway
- Bitdefender GravityZone
- Microsoft 365
- CCTV / NVR
- Alarm sistemleri
